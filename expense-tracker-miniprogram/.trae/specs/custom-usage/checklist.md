# 常用账单自定义用途 - 验证清单

## 功能验证

- [ ] 常用账单能正确存储和读取用途数据
- [ ] 现有常用账单能自动迁移，创建默认用途
- [ ] 能在常用账单管理页面添加新用途
- [ ] 能在常用账单管理页面编辑现有用途
- [ ] 能在常用账单管理页面删除用途（带确认提示）
- [ ] 能设置某个用途为默认用途
- [ ] 首页点击有多个用途的常用账单时显示用途选择弹窗
- [ ] 首页点击只有一个用途的常用账单时直接记账
- [ ] 设置了默认用途的常用账单能跳过选择直接记账
- [ ] 选择用途后能正确保存账单
- [ ] 记账页面选择有多个用途的常用账单时显示用途选择
- [ ] 选择用途后能正确填充表单信息

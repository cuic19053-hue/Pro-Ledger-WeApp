# 账单管理小程序 - 从零开始重做 Verification Checklist

## 产品气质验证
- [ ] 产品气质：极简/克制/高级/金融感/信任感
- [ ] 用户感受：打开像在用一个"可靠的工具"，而不是小程序

## 配色系统验证
- [ ] 主色：深蓝/墨绿/高级灰方向
- [ ] 背景：浅灰或纯白
- [ ] 无高饱和颜色
- [ ] 无廉价渐变
- [ ] 完整灰度体系（专业级）

## 布局系统验证
- [ ] 大留白（不拥挤）
- [ ] 信息分组（卡片化）
- [ ] 一屏一重点
- [ ] 减少50%元素

## 字体系统验证
- [ ] 金额：超大+加粗（视觉中心）
- [ ] 其他信息：全部弱化
- [ ] 3层信息层级以内
- [ ] 金融数字使用tabular-nums

## 丑设计删除验证
- [ ] 无多余边框
- [ ] 无花哨渐变
- [ ] 无图标乱用
- [ ] 无信息堆叠
- [ ] 模块权重合理

## 首页重做验证
- [ ] 本月支出（最大，视觉中心）
- [ ] 收入/结余（次级）
- [ ] 一个简单图表
- [ ] 最近3条账单
- [ ] 没有堆功能

## 记账页重做验证
- [ ] 像计算器一样快
- [ ] 1-2步完成输入
- [ ] 大数字输入框
- [ ] 分类选择极简
- [ ] 快速确认

## 统计页重做验证
- [ ] 图表干净清晰
- [ ] 无复杂UI
- [ ] 数据层级明确
- [ ] 大留白

## 动效重做验证
- [ ] 所有出现：淡入（fade）
- [ ] 所有点击：轻微缩放0.97
- [ ] 所有切换：滑动或渐变
- [ ] 禁止弹跳动画
- [ ] 禁止花哨特效
- [ ] 像iPhone系统一样自然

## 全局验证
- [ ] 像一个"真实公司产品"
- [ ] 而不是学生作品
- [ ] 可以直接用于接单/上线/赚钱
- [ ] 整体体验一致性
- [ ] 准备上线

# 前端显示问题修复计划

## 问题分析

经过检查，发现项目代码存在以下不一致问题：

### 1. 设计系统混乱
- `app.wxss` 定义了一套新的设计系统（绿色系、大量 CSS 变量）
- 但页面文件使用了完全不同的类名和结构
- 没有统一的视觉风格

### 2. CSS 变量缺失
页面 WXSS 中使用了很多 CSS 变量，但在 app.wxss 中找不到：
- `--shadow-md`（页面使用但未定义）
- `--bg-elevated`（页面使用但未定义）
- `--text-tertiary`（页面使用但未定义）
- `--color-primary-*`（部分变量可能不一致）

### 3. 页面结构不一致
- 首页 WXML 使用了 `.summary-card`、`.stats-grid` 等类
- 但 app.wxss 中定义的是 `.card`、`.list-item` 等类
- 两套设计系统混用

### 4. 文件版本混乱
- 部分文件使用了旧的设计
- 部分文件使用了新的设计
- 没有统一的视觉风格

## 修复方案

### 方案一：统一到绿色系新设计（推荐）
将所有页面统一到 app.wxss 中定义的新设计系统（绿色系、更完整的设计系统）

**需要修改的文件：**
1. `pages/home/home.wxml` - 重写为使用新的卡片结构
2. `pages/home/home.wxss` - 删除旧样式，使用 app.wxss 的通用样式
3. `pages/bills/bills.wxml` - 重写为使用新的卡片结构
4. `pages/bills/bills.wxss` - 删除旧样式，使用 app.wxss 的通用样式
5. `pages/stats/stats.wxml` - 检查并统一
6. `pages/add/add.wxml` - 检查并统一
7. `pages/profile/profile.wxml` - 检查并统一
8. `pages/login/login.wxml` - 检查并统一

### 方案二：回退到流体商务设计
将 app.wxss 回退到之前的"流体商务 Elite Fluidity"设计（爱马仕橙、24rpx 圆角）

**需要修改的文件：**
1. `app.wxss` - 回退到之前的爱马仕橙设计
2. 所有页面保持不变

## 推荐方案

**推荐方案一：统一到绿色系新设计**

理由：
1. 新的设计系统更完整（有完整的灰度体系、更多色彩变量）
2. 绿色系更符合记账应用的调性
3. app.wxss 已经写好了完整的设计系统

## 实施步骤

### 第一步：备份当前状态
- 先确认用户想使用哪套设计

### 第二步：重写首页
1. 重写 `pages/home/home.wxml` 使用新的卡片结构
2. 简化 `pages/home/home.wxss` 只保留必要的样式
3. 确保使用 app.wxss 中定义的类名

### 第三步：重写账单页
1. 重写 `pages/bills/bills.wxml` 使用新的卡片结构
2. 简化 `pages/bills/bills.wxss` 只保留必要的样式

### 第四步：统一其他页面
1. 检查并统一 stats、add、profile、login 页面
2. 确保所有页面使用一致的设计系统

### 第五步：测试验证
1. 在微信开发者工具中预览
2. 检查所有页面的显示效果
3. 确保没有样式错误

## 风险提示

1. **工作量较大**：需要重写多个页面的 WXML 和 WXSS
2. **需要用户确认**：必须先确认用户想使用哪套设计系统
3. **可能破坏功能**：重写时要确保不破坏现有功能逻辑

## 建议

在开始修复前，先询问用户：
1. 想使用哪套设计系统？
2. 绿色系新设计 vs 爱马仕橙流体商务设计？

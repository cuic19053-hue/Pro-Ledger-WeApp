# 数据库集成实现计划

## [x] 任务 1: 开通微信云开发环境
- **优先级**: P0
- **依赖**: 无
- **描述**:
  - 在微信开发者工具中开通云开发环境
  - 获取云环境ID并配置到项目中
- **成功标准**:
  - 云开发环境创建成功
  - 项目能正确初始化云开发
- **测试要求**:
  - `programmatic` TR-1.1: 云开发控制台显示环境状态正常
  - `programmatic` TR-1.2: 小程序能成功初始化云开发
- **备注**: 云开发有免费额度，足够个人使用

## [x] 任务 2: 配置云开发初始化
- **优先级**: P0
- **依赖**: 任务 1
- **描述**:
  - 修改 app.js 文件，添加云开发初始化代码
  - 配置云环境ID
- **成功标准**:
  - 小程序启动时能正确初始化云开发
  - 无初始化错误
- **测试要求**:
  - `programmatic` TR-2.1: 控制台无云开发初始化错误
  - `programmatic` TR-2.2: 能成功调用云函数
- **备注**: 确保使用正确的云环境ID

## [x] 任务 3: 创建数据库集合
- **优先级**: P0
- **依赖**: 任务 2
- **描述**:
  - 在云开发控制台创建 users 集合（存储用户信息）
  - 创建 bills 集合（存储消费记录）
  - 设置安全规则，确保用户只能访问自己的数据
- **成功标准**:
  - 两个集合创建成功
  - 安全规则设置正确
- **测试要求**:
  - `programmatic` TR-3.1: 集合创建成功且可见
  - `programmatic` TR-3.2: 安全规则验证通过
- **备注**: 安全规则是保护用户数据的关键

## [x] 任务 4: 改造登录功能
- **优先级**: P1
- **依赖**: 任务 3
- **描述**:
  - 修改 login.js，使用云函数进行登录
  - 登录成功后保存用户信息到 users 集合
  - 实现用户信息持久化
- **成功标准**:
  - 登录功能正常工作
  - 用户信息正确保存到数据库
- **测试要求**:
  - `programmatic` TR-4.1: 登录成功后数据库中出现用户记录
  - `human-judgement` TR-4.2: 登录流程流畅无卡顿
- **备注**: 确保获取用户的 openid 作为唯一标识

## [x] 任务 5: 改造账单存储功能
- **优先级**: P1
- **依赖**: 任务 4
- **描述**:
  - 修改 add.js 和 app.js，将账单保存到云数据库
  - 实现账单的增删改查功能
  - 确保只显示当前用户的账单
- **成功标准**:
  - 账单能正确保存到云数据库
  - 只能看到自己的账单
- **测试要求**:
  - `programmatic` TR-5.1: 新增账单后数据库中出现记录
  - `programmatic` TR-5.2: 只能查询到自己的账单
- **备注**: 每个账单都需要关联用户的 openid

## [x] 任务 6: 改造数据加载功能
- **优先级**: P1
- **依赖**: 任务 5
- **描述**:

  - 实现数据的实时更新
- **成功标准**:
  - 各页面能正确加载云数据库中的数据
  - 数据显示正确且实时
- **测试要求**:
